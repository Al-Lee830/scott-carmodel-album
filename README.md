# AI 模型藝廊 (Model Album)

一個專業、現代且具備管理功能的 3D 模型圖庫網站。

## 功能特點
- **現代化視覺設計**：深色模式、玻璃擬態風格。
- **管理模式**：支援新增、編輯與刪除模型資訊。
- **本地儲存**：使用瀏覽器 `localStorage` 儲存您的編輯內容。
- **雙來源新增**：可從 `images` 資料夾選取或直接上傳新圖片。
- **響應式設計**：完美支援各種螢幕尺寸。

## 如何使用
1. 下載此專案。
2. 在瀏覽器中開啟 `index.html` 即可。

## 技術棧
- HTML5 / CSS3 (Vanilla)
- JavaScript (Vanilla)
